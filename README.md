Numerical-Analysis

Some simple code examples in numerical analysis and linear algebra.

Cholesky_least_square.py contains the Python code for Oblig 1 in the course MAT4110: Introduction to Numerical Analysis, Autumn 2024.

MAT4110 Oblig1 H2024.pdf and MAT4110 Oblig2 H2024.pdf are the complete mandatory assignments (Oblig 1 and Oblig 2) for the same course, including all written answers.

LU_decomposition.py, backward_substitution.py, forward_substitution.py, and Gauss-Seidel_iteration.py are additional codes I wrote based on the algorithms and topics covered in the lectures.

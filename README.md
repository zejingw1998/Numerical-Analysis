Numerical-Analysis

Some simple code examples in numerical analysis and linear algebra.

Cholesky_least_square.py contains the solution to Oblig 1, the first mandatory assignment for the course MAT4110: Introduction to Numerical Analysis, Autumn 2024.

LU_decomposition.py, backward_substitution.py, forward_substitution.py, and Gauss-Seidel_iteration.py are codes I wrote based on the algorithms and topics covered in the course lectures.

MAT4110 Oblig 1 and Oblig 2 are the mandatory assignments for MAT4110: Introduction to Numerical Analysis, Autumn 2024.
